**A consumer grievance intelligence platform bringing complaint intake, explainable NLP-assisted triage, and human review into a single workflow.**

| Engineering focus | Implementation |
| --- | --- |
| **End-to-end product** | React + TypeScript frontend, Spring Boot REST API, FastAPI NLP microservice, PostgreSQL |
| **Explainable ML** | TF-IDF and Logistic Regression production classifier; separate BiLSTM benchmarking |
| **Responsible workflows** | Human-in-the-loop reviewer decisions, PII scrubbing, audit trails and tracked case status |
| **Defensive backend** | Role-separated database access, credential hashing, rate limiting and concurrency controls |

**Architecture:** React / TypeScript → Spring Boot → FastAPI NLP → PostgreSQL
