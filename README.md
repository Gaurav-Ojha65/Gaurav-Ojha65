### 2. Real-Time ASL Gesture Recognition

A webcam-based fingerspelling system that converts hand gestures into text through landmark-based classification and temporal control logic.

- MediaPipe extracts 3D hand landmarks; preprocessing normalizes hand geometry and handedness.
- A lightweight PyTorch MLP classifies gestures.
- A temporal finite-state machine controls gesture commitment, release debounce, and text assembly.
- Includes a separate CNN benchmark for the Sign Language MNIST dataset.

**Stack:** Python · MediaPipe · PyTorch · OpenCV · NumPy · pytest

→ [View repository](https://github.com/Gaurav-Ojha65/ASL-Gesture-Recognition)
